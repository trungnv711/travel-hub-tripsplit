Hướng dẫn cấu hình từng bước
  1. Tạo dự án Apps Script mới.
  2. Tải Code.gs, mở file rồi dán toàn bộ vào trình soạn thảo Apps Script và bấm Lưu.
  3. Vào Project Settings → Script Properties, thêm tên TRIPSPLIT_SECRET và dùng cùng mã bí mật bên dưới.
  4. Chọn Deploy → New deployment → Web app; đặt Execute as: Me và Who has access: Anyone.
  5. Cấp quyền, sao chép URL kết thúc bằng /exec rồi dán vào ô Web App URL.

URL và mã bí mật chỉ lưu trên thiết bị này. Không gửi mã bí mật cho người khác.
